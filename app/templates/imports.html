Recognized columns

The importer recognizes common variations of these fields:

  • RequiredTender title · Organization / Procuring Entity
  • Notice identificationNotice number / IFB number / Reference number
  • DatesPublished date · Submission deadline · Bid opening date
  • LocationProvince · District · Municipality
  • DetailsCategory · Description · Budget · Bid security
  • LinksSource URL · Bid document URL

Duplicate notices are detected by notice number, source URL, or matching title and organization. Existing records are not overwritten; only missing details may be filled. New imports remain pending admin verification and are not automatically marked verified.
